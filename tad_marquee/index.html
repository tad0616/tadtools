簡介

TadMarquee 是一套純 JavaScript 跑馬燈套件，無需任何外部依賴，支援四方向捲動、無縫循環播放，並完整符合 WCAG AAA 無障礙標準。

特色說明
四方向捲動left、right、up、down
無縫循環第 N 則後自動接回第 1 則，不跳動
暫停按鈕6 種位置，含 input-group 並排模式
鍵盤導航方向鍵、Home/End、Space/Enter、Escape
螢幕閱讀器ARIA 標籤、即時播報、複本隱藏
響應式速度依螢幕寬度自動調整捲動速度
reduced-motion尊重系統動畫偏好設定

快速開始

引入檔案

<!-- CSS -->
<link rel="stylesheet" href="tad_marquee.css">
<!-- JS -->
<script src="tad_marquee.js"></script>

HTML 容器

<div id="my-marquee" style="width:100%; height:44px;"></div>

初始化

const marquee = new TadMarquee('my-marquee', {
direction: 'left',
speed: 60,
items: [
  { type: 'text', content: '第一則公告' },
  { type: 'text', content: '第二則公告' },
  { type: 'text', content: '第三則公告' }
]
});

項目格式

文字

{ type: 'text', content: '公告內容',
style: 'color:red; font-weight:bold', // 可選
className: 'my-class' }             // 可選

圖片

{ type: 'image', content: 'https://example.com/img.png',
alt: '圖片說明', text: '附加文字' }

HTML

{ type: 'html', content: '<strong>重要</strong> 公告' }

含連結（任何類型皆可加）

{ type: 'text', content: '點我前往',
link: 'https://example.com',
target: '_blank',
rel: 'noopener noreferrer',
ariaLabel: '前往範例網站（另開新視窗）' }

樣式選項

選項型別說明
itemStylestring|object全域項目行內樣式，支援 CSS 字串或 JS 物件
itemClassNamestring全域項目 CSS 類別

// JS 物件格式
itemStyle: { color: '#fff', fontSize: '15px', padding: '0 8px' }

API：播放控制

所有方法皆回傳 this，支援鏈式呼叫。

marquee.start()    // 開始播放
marquee.stop()     // 停止播放並重置狀態
marquee.pause()    // 暫停（保持目前位置）
marquee.resume()   // 從暫停處繼續

API：內容更新

// 更換所有項目
marquee.updateItems([
{ type: 'text', content: '新公告一' },
{ type: 'text', content: '新公告二' }
]);

// 修改捲動速度
marquee.setSpeed(80);

// 修改捲動方向（會重建 DOM 結構）
marquee.changeDirection('up');

API：樣式更新

// 合併更新（預設）
marquee.setItemStyle('color:red; font-size:18px');
marquee.setItemStyle({ color: 'red' });

// 完全取代
marquee.setItemStyle({ color: 'blue' }, false);

// 更換 CSS 類別
marquee.setItemClassName('new-class', 'old-class');

API：查詢狀態

// 取得所有設定
const opts = marquee.getOptions();

// 取得執行狀態
const status = marquee.getStatus();
// 回傳：{
//   isRunning, isPaused, isPausedByUser,
//   direction, speed, itemCount, isSingleItem,
//   prefersReducedMotion, currentBreakpoint,
//   loopSize, inlineMode
// }

// 銷毀並還原 DOM
marquee.destroy();

new TadMarquee('my-marquee', {

鍵盤操作

按鍵功能
Tab將焦點移至暫停按鈕或內部連結
Space / Enter切換暫停／繼續（焦點在容器上時）
→ / ↓聚焦下一個項目
← / ↑聚焦上一個項目
Home聚焦第一個項目
End聚焦最後一個項目
Escape移除焦點，離開跑馬燈
💡 焦點移入暫停按鈕時，Enter/Space 由瀏覽器原生行為觸發按鈕點擊，不會與容器層的鍵盤事件衝突。

無障礙設計說明

WCAG 準則等級實作方式
1.3.1 資訊與關係 A role="region"、role="list"、role="listitem"、aria-label
1.4.3 色彩對比 AA 暫停按鈕白色圖示對半透明黑底，對比度 > 4.5:1
2.1.1 鍵盤 A 所有功能均可透過鍵盤操作，無滑鼠陷阱
2.2.2 暫停、停止、隱藏 A 提供可見暫停按鈕，使用者可隨時暫停捲動
2.3.3 動畫（三閃或低於閾值） AAA 尊重 prefers-reduced-motion，偵測到時自動暫停
2.4.11 焦點外觀 AA 焦點時顯示 3px 黃色外框 + 光暈效果
2.5.5 目標尺寸 AAA 並排按鈕 40px 寬、角落按鈕 32px，觸控友善
4.1.2 名稱、角色、值 A aria-pressed、aria-label 動態更新反映按鈕狀態

螢幕閱讀器行為

  • 複本項目（無縫循環用）統一設定 aria-hidden="true" 及 tabindex="-1"
  • 鍵盤導航僅能聚焦原始組的項目，不會重複播報
  • 操作（暫停、繼續、方向變更）透過 role="status" 的隱藏元素即時播報

DOM 結構說明

角落模式

#my-marquee.tad-marquee-container ← 原始容器（position: relative） ├── div.tad-marquee-wrapper ← 捲動內容（position: absolute） │ ├── div.tad-marquee-item ← 原始項目（可被 AT 讀取） │ ├── div.tad-marquee-gap │ ├── div.tad-marquee-item │ ├── div.tad-marquee-gap │ ├── div.tad-marquee-item aria-hidden="true" ← 複本 │ └── ... └── button.tad-marquee-pause-btn ← 浮動圓形按鈕（position: absolute）

並排模式（left / right）

div.tad-marquee-root.tad-marquee-inline ← 自動插入外層（display: flex） ├── button.tad-marquee-pause-btn ← 左側按鈕（position: left 時） ├── #my-marquee.tad-marquee-container ← 原始容器（flex: 1） │ └── div.tad-marquee-wrapper │ └── ...（同上） └── button.tad-marquee-pause-btn ← 右側按鈕（position: right 時）

範例四：動態更新內容

const marquee = new TadMarquee('my-marquee', {
direction: 'left',
items: [{ type: 'text', content: '初始內容' }]
});

// 3 秒後更換內容
setTimeout(() => {
marquee.updateItems([
  { type: 'text', content: '更新後的第一則' },
  { type: 'text', content: '更新後的第二則' }
]);
}, 3000);

marquee.setSpeed(100);
console.log(marquee.getStatus());
