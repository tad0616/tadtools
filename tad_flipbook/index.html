AccessiblePdfFlipbook 範例頁

使用 PDF.js + StPageFlip 的無障礙 PDF 翻頁書,以 WCAG 2.2 AAA 為目標。

鍵盤操作說明

  • Tab / Shift+Tab:在控制項之間移動焦點
  • ← / PageUp:上一頁
  • → / PageDown:下一頁
  • Home:第一頁;End:最後一頁
  • Enter / Space:焦點在內容區時翻至下一頁;焦點在按鈕上時啟動該按鈕
  • 頁碼輸入框中按 Enter 可直接跳頁

本翻頁書以圖片呈現 PDF 頁面,螢幕閱讀器無法逐字讀取內文; 請使用翻頁書上方的「下載原始 PDF」連結取得完整文字版本。
